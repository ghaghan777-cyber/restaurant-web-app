# 🍽️ Restaurant Website

## 📌 Project Description
This is a simple and attractive Restaurant Website developed using HTML and CSS. It provides information about the restaurant, its food menu, special offers, customer reviews, and contact details.

The website is designed with a beautiful layout, attractive food images, and a user-friendly interface.

## ✨ Features
- 🏠 **Home Section** – Attractive welcome page with a hero section.
- 🍕 **Food Menu** – Displays different food items with images and prices.
- 🎉 **Special Offers** – Highlights special discounts and offers.
- ⭐ **Customer Reviews** – Displays customer feedback and ratings.
- 📍 **Contact Section** – Provides restaurant location and contact information.
- 📱 **Responsive Design** – Supports different screen sizes.

## 🛠️ Technologies Used
- HTML5
- CSS3

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Find the `index.html` file.
4. Double-click `index.html` to open it in your browser.
5. Explore the restaurant website.
